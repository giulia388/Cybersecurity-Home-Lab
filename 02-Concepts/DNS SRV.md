Un record DNS SRV (Service Record) è un tipo di record DNS che permette a un computer di scoprire quale server **offre un determinato servizio di rete e su quale porta è disponibile.**

### Record A vs Record SRV

- Record A: permette di trovare l'indirizzo IPv4 di un computer conoscendone il nome.
    
- Record SRV: permette di trovare il server che offre un determinato servizio, ad esempio [[LDAP]] o [[Kerberos]].
